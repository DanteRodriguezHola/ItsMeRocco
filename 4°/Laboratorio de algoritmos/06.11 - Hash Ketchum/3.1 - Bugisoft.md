En una hash table con un arreglo asociado de tamaño 11, vamos insertando las siguientes keys en este orden: 

*9, 26, 50, 15, 2, 21, 36, 22 y 32.*

Utiliza **Exploración lineal (linear probing)** para resolver los problemas de colisiones (Suponé que el arreglo nunca se redimensiona).

**=== RESOLUCIÓN DEL EJERCICIO ===**

Primero, creamos nuestro hash table con 11 buckets.

**hash_table**:
[
    None, # 0
    None, # 1
    None, # 2
    None, # 3
    None, # 4
    None, # 5
    None, # 6
    None, # 7
    None, # 8
    None, # 9
    None, # 10
]

Despues, obtenemos el indice para cada key, utilizando la función esa del ejercicio ese:

9: 9
26: 4
50: 6
15: 4
2: 2
21: 10
36: 3
22: 0
32: 10

Ahora si, la parte divertida: *insertar las keys a la hash table*.
Las primeras tres keys **(9, 26 y 50)** se insertan sin mucho problema, *porque tienen indice unicos.* 

**hash_table**:
[
    None, # 0
    None, # 1
    None, # 2
    None, # 3
    **26**, # 4
    None, # 5
    **50**, # 6
    None, # 7
    None, # 8
    **9**, # 9
    None, # 10
]

La cuarta key, 15, *tiene un indice repetido (4)*.
Para solucionarlo, recorremos el hash para encontrar el primer bucket que este vacio.
En este caso, el bucket 0 esta vacio, asi que insertamos ahí la key.

**hash_table**:
[
    **15**, # 0
    None, # 1
    None, # 2
    None, # 3
    26, # 4
    None, # 5
    50, # 6
    None, # 7
    None, # 8
    9, # 9
    None, # 10
]

Las siguientes tres keys **(2, 21 y 36)** *tienen indices unicos*,
asi que las insertamos sin mucha complicación.

**hash_table**:
[
    15, # 0
    None, # 1
    **2**, # 2
    **36**, # 3
    26, # 4
    None, # 5
    50, # 6
    None, # 7
    None, # 8
    9, # 9
    **21**, # 10
]

**22** tiene *un indice repetido (0)*.
El primer bucket vacio es el 1, asi que lo ponemos ahí.

**hash_table**:
[
    15, # 0
    **22**, # 1
    2, # 2
    36, # 3
    26, # 4
    None, # 5
    50, # 6
    None, # 7
    None, # 8
    9, # 9
    21, # 10
]

Por ultimo, **32** tiene *un indice repetido (10)*.
El primer bucket vacio es el 5, asi que lo ponemos ahí.

**hash_table**:
